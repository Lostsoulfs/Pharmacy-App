# Architecture Decision Records

This directory records decisions that change repository rules, source
boundaries, clinical/legal risk posture, verification gates, or app
architecture.

Use one ADR per durable decision. Keep entries factual:

- Context: what forced the decision.
- Decision: what changed.
- Consequences: what this enables and what it does not prove.
- Confirmation: commands, review state, or remaining evidence.

ADR numbers are local to this repository.
